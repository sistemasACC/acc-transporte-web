# Sitio web de ACC Transporte

Esta es la versión independiente del sitio corporativo de ACC Transporte. No necesita ChatGPT, bases de datos, Node.js ni servicios privados para funcionar.

## Archivos principales

- `index.html`: contenido de la página.
- `styles.css`: colores, diseño y adaptación para celulares.
- `assets/`: logo, fotografía principal y favicon.
- `GUIA-PASO-A-PASO.md`: instrucciones para publicarlo y modificarlo.

## Probarlo en la computadora

Puedes abrir `index.html` directamente con el navegador. Para una prueba más completa desde Visual Studio Code, instala la extensión **Live Server**, abre esta carpeta y selecciona **Open with Live Server** sobre `index.html`.

## Publicación

El sitio está preparado para GitHub Pages. No contiene contraseñas, claves, conexiones a ChatGPT ni información secreta.
